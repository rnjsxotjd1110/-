# 06. 스타일 가이드

## 1. 픽셀 격자
- 내부 캔버스 **640×360** 하나에 모든 것을 그린다. 창 크기에 맞춰 **정수 배율**(1×, 2×, 3×, 4×…)로만 확대하고 남는 곳은 팔레트 0번 색으로 채운다(레터박스).
- 좌표는 항상 정수(`|0`). 회전·축소는 저해상도 캔버스 안에서 픽셀 단위로 계산한다. 반투명 혼합 금지 — 캔버스에 그리는 모든 픽셀은 팔레트 색 그대로다.
- 브라우저 확대는 `image-rendering: pixelated` + 정수 CSS 크기.

고른 이유
- 우주 테마에 흔한 남색 배경·보라·청록 네온을 쓰지 않는다. 이 팔레트는 갈색·적갈·황토·크림 중심이라 우주를 "오래된 천문대의 놋쇠 기계와 그을린 하늘"로 보이게 한다. 다른 우주 증분형과 스크린샷 한 장으로 구별된다.
- 상아 주사위(크림 4 → 복숭아 8 → 진흙 9 → 회갈 14), 놋쇠(금 3 → 황토 2 → 갈 11 → 녹 18) 램프가 자연스럽게 나온다.

## 3. 명암 램프 (밝음 → 어두움, 어두울수록 색상이 붉은·갈색 쪽으로 이동)

| 램프 | 색 번호 | 쓰는 곳 |
| --- | --- | --- |
| 상아 | 4 → 8 → 9 → 14 | 주사위 몸체, 크림 글자 |
| 놋쇠 | 3 → 2 → 11 → 18 | UI 프레임, 궤도 기계 |
| 돌 | 15 → 14 → 13 → 12 | 패널 바탕, 비활성 |
| 주황 | 8 → 7 → 5 → 10 → 21 | 가스 거성, 별핵 |
| 적 | 7 → 17 → 20 → 22 → 23 | 적색 왜성, 경고 |
| 청록 | 19 → 16 → 6 → 0 | 바다 행성, 특이점 |
| 녹 | 2 → 1 → 0 | 바다 행성 땅 |

- **광원은 왼쪽 위 하나로 고정**한다. 주사위, 행성, UI 베벨(왼쪽 위 밝은 1px, 오른쪽 아래 어두운 1px) 모두 같다.
- 외곽선: 스프라이트는 바깥 1px 외곽선(색 12 또는 그 램프의 가장 어두운 색). 굵기는 어디서나 1px. 필로우 셰이딩(가운데 밝고 사방 어두운 음영) 금지.

## 4. 디더링 규칙
- 그라데이션은 디더링으로만 표현한다(혼합색 금지).
- 단, **넓은 면을 바둑판 점무늬로 채우지 않는다.** 평평한 색 단계 사이의 경계에만 2~3px 폭의 순서 디더(Bayer 4×4)를 둔다. 행성 명암 경계, 성운 가장자리, 중심별 코로나에만 쓴다.

## 5. 글꼴
- **갈무리(Galmuri) 2.40.3, SIL OFL 1.1.** BDF 비트맵을 그대로 읽어 저해상도 캔버스에 찍는다. 안티앨리어싱이 원천적으로 없다.
- Galmuri11(12px): 본문 / Galmuri11 Bold(12px): 제목·숫자 강조 / Galmuri9(10px): 보조 / Galmuri7(8px): 궤도 번호 같은 아주 작은 표시.
- 로고는 Galmuri11 Bold를 정수 3배로 확대한 뒤 손으로 그림자·하이라이트를 더한 픽셀 로고.
- 글자 색은 팔레트 색, 그림자는 1px 아래 색 12.

## 6. UI 규칙
- 재질은 세 가지만: **놋쇠 판**(패널 테두리, 9-slice), **홈 파인 칸**(입력·게이지·주사위 쟁반 바닥), **종이 딱지**(툴팁·알림, 크림 바탕).
- 버튼은 놋쇠 9-slice 4상태(기본·올림·눌림·불가). 둥근 모서리 카드, 그림자 박스, 그라데이션, 글로우, 블러, 이모지, 아이콘 폰트 금지.
- 목록의 줄마다 상자를 씌우지 않고 홈(어두운 1px + 밝은 1px 선)으로 나눈다. 상자 안의 상자는 두 겹까지.
- 탭은 글자 + 2px 밑줄.
- 글자 위계 3단: 제목(Bold 12) / 본문(11) / 보조(9). 
- 색의 뜻은 하나씩: 금(3) = 살 수 있음·받기, 주황(7) = 별핵, 청록(19) = 특이점, 적(17) = 부족·경고, 크림(4) = 일반 글자, 회갈(15) = 보조 글자.
- 메인 메뉴는 상자 버튼 금지: 글자 + 왼쪽에 작은 주사위 선택 표시. 빈 곳을 눌러도 시작된다.
- 당연한 사실을 설명하지 않는다. 설명줄 기본값은 "없음".
- 문구: 화면 문구는 해요체, 버튼은 "~하기" 꼴. 단어 하나 뒤 쉼표 금지. 느낌표는 큰 순간에만 1개.

## 7. 연출 원칙
- 굴림: 주사위가 쟁반 위를 튀며 구른다(실시간 3D 렌더 → 팔레트 양자화). 착지 때 쟁반이 1~2px 흔들린다.
- 결과 확정: 합 숫자가 튀어 오르고, 궤도까지 빛 줄기(픽셀 점선)가 날아가 천체에 닿는다.
- 정렬: 화면 흔들림 2px, 모든 궤도가 한 번 밝아짐, 큰 숫자.
- 단계 상승: 천체 주변에 픽셀 파티클 링, 이름 딱지.
- 구매: 버튼 눌림 + 숫자 감소 카운트 + 작은 불꽃.
- 해금: 새 항목이 왼쪽에서 밀려 들어오며 금색 테두리 깜빡임 2회.
- 초신성: 중심별 팽창 → 흰 크림 섬광(팔레트 색만) → 파편 파티클 → 성운이 남음.
- 결과가 클수록 연출도 커진다(희소도·정렬·단계에 비례해 파티클 수·흔들림·숫자 크기 단계).
- "연출 줄이기" 설정에서 흔들림과 섬광을 끈다.

## 8. 성장이 화면에 보이는 장치
- 궤도 수 증가(주사위 수·눈 새기기), 천체 10단계 외형, 중심별 6단계, 배경 5단계(성운 → 먼 은하 → 성단 → 블랙홀 원반 → 천구 격자), UI 놋쇠 장식이 층마다 늘어남.
