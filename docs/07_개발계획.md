# 07. 개발 계획

## 기술 선택
- **HTML5 Canvas + 순수 JavaScript(빌드 도구 없음)**. 이 환경에서 Chromium(Playwright)으로 직접 띄워 화면을 캡처·조작할 수 있고, 같은 게임 로직 파일을 Node.js 시뮬레이터에서 그대로 불러 쓸 수 있다. 결과물은 브라우저로 바로 실행되고, 이후 Electron/Capacitor로 Steam·모바일 포장이 가능하다.
- Godot/Unity/Unreal은 이 클라우드 환경에서 실행·캡처 확인이 어렵다(작업 환경 원칙 "직접 띄워 보지 못한 결과물은 완성으로 치지 않는다").

## 폴더
```
index.html          실행 파일
src/                게임 코드 (core/*는 Node에서도 동작하는 순수 로직)
tools/              화면 점검, 캡처, 시뮬레이터, 글꼴 변환
docs/               기획 문서, progress.md, decisions.md
docs/img/           캡처
```
