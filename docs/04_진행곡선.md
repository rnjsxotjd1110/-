# 04. 진행 곡선

"평범한 플레이" 기준(가끔 손으로 굴리고, 살 수 있으면 대체로 바로 사는 사람). 시간은 실제 경과 시간이며 방치 시간을 포함한다. 시뮬레이터 결과로 목표 범위를 검증한다(08_밸런스.md).

| 시점 | 목표 범위 | 새로 보게 되는 것 | 새로 내리는 결정 |
| --- | --- | --- | --- |
| 첫 10초 | 0~10초 | 상아 주사위 2개, 빈 궤도 11개, 중심별. 굴리면 합의 궤도에 먼지 구름이 생긴다 | 굴리기 |
| 첫 1분 | 0~1분 | 첫 구매(굴림 힘), 미행성 첫 탄생, 정렬(같은 눈) 첫 경험, 태엽 굴림대 해금 | 굴림 힘 대 태엽 굴림대 중 무엇부터 살지 |
| 3~5분 | 2~6분 | 일회성 업그레이드 목록 등장, 암석 행성, 첫 하늘 이벤트(혜성) | 업그레이드 순서, 이벤트 잡기 |
| 10분 | 7~14분 | 세 번째 주사위(궤도 3~18로 확장), 눈 새기기 해금, 바다·고리 행성 | 어느 면을 새길지(가장자리 노리기 대 고르게), 조화 대 몰아주기 |
| 30분 | 20~40분 | 가스 거성, 네 번째 주사위, 갈색 왜성 | 주사위 추가 시점(분포가 가운데로 몰리는 손해 대 궤도 확장) |
| 1시간 / 첫 초신성 | 40~70분 | 첫 적색 왜성 탄생 → 초신성 열림. 초신성 연출, 별핵 획득 | 지금 터뜨릴지 더 키울지(별핵 미리보기) |
| 첫 환생 직후 | 70~80분 | 별핵 연구 갈래 3개(성장·굴림·하늘), 중심별 색 변화, 배경에 첫 성운 | 연구 갈래 선택 |
| 2~3시간 | 1.5~3.5시간 | 넘치는 눈(면 최대 9), 바깥 궤도, 관측 과제 6개 해금, 다섯 번째 주사위 | 과제 순서, 바깥 궤도 투자 |
| 3시간 | 2~4시간 (수정) | 백색 왜성·중성자별, 중력 붕괴 열림, 블랙홀 연출, 특이점 | 붕괴 시점, 특이점 연구, 별핵 정제 |
| 5~9시간 | 4~10시간 (수정) | 다면체 주사위(d4 정렬·d8 희소도·d12 질량), 여섯 번째 칸, 특이점 압축, 붕괴 자동화 | 주사위 구성, 특이점을 압축에 쓸지 연구에 쓸지 |
| 엔딩 | 6~14시간 (재수정) | 천구 완성 장치, 엔딩. 이후 무한 진행(업적·통계 채우기) | 엔딩 시점, 엔딩 뒤 기록 도전 |

## 기다리기만 하는 시간이 없도록 한 장치
- 구매 가능 항목이 없을 때도 할 수 있는 일: 손으로 굴리기(최대 ×3 효율), 눈 새기기 계획, 하늘 이벤트 잡기
- 다음 구매까지 걸리는 시간 목표: 평범한 플레이 기준 30분 이전 20~60초, 1시간 이후 1~3분, 최장 5분
- 환생 직후 시작 상태를 연구로 끌어올려(태엽 유지, 주사위 3개로 시작 등) 같은 길 반복 시간을 줄인다
- 초신성·붕괴 미리보기: 지금 하면 얻을 양과 "다음 1개까지 남은 양"을 항상 보여 준다

## 수정 이력
- 2026-11-23: 증분형 고인물 검수(V1-1)의 "엔딩 직전 15시간 벽, 엔딩은 12~15시간 권장" 지적에 따라 붕괴 2~4시간, 엔딩 10~22시간으로 목표를 앞당겼다(평범 13시간, 방치 22시간).
- 2026-11-23: 고인물 2차(V2-2) "5시간 이후 새로 열리는 것 없음" 지적에 따라 엔딩을 8~14시간으로 다시 앞당김(평범 9.2시간).
