# 03. 게임 이름

## 후보

| 후보 (한국어 / 영어) | 핵심 재미와의 연결 | 검색 결과 (2026-11-23, Steam·Google Play·itch.io 대상 웹 검색) | 판정 |
| --- | --- | --- | --- |
| 주사위 성계 / Dice Orrery | 주사위 + 태양계 모형 기계. 놋쇠 기계라는 화면 정체성과 맞다 | "Dice Orrery", "Orrery Dice" 이름의 게임·앱 없음. Steam "Orrery"(데스크톱 유틸리티), Playdate "Orrery"(천문 도구), "Solar Orrery"(iOS 교육 앱) 등 "Orrery" 단독 이름만 있음. "주사위 성계" 한국어 제목 없음 | **확정** |
| 합궤도 / Sumorbit | 합 = 궤도 규칙을 그대로 | "Sumorbit"(행성 스모 격투, Steam·Switch·Xbox 출시) 존재 | 탈락: 동명 게임 |
| 열한 궤도 / Eleven Orbits | 2d6의 궤도 11개 | 동명 없음. "12 orbits"(Steam 파티 게임), "Orbits"(Steam) 유사 | 탈락: 유사 이름 존재, 주사위를 늘리면 11이 아니게 됨 |
| 구르는 성계 / Rolling Orrery | 굴림 + 오러리 | 동명 없음. 보드게임 "Empire of the Rolling Spheres"와 어감 유사 | 탈락: 한국어 "구르는"이 행성이 굴러간다는 오해를 준다 |
| 확률 성계 / Probability System | 확률 분포가 성계 | 동명 없음 | 탈락: 영어가 수학 교재 같고 억지스럽다 |
| 일곱째 궤도 / The Seventh Orbit | 2d6에서 가장 흔한 합 7 | "Seventh orbit" 이름의 소규모 게임 다수 | 탈락: 흔한 SF 이름 |

## 확정
- 한국어: **주사위 성계**
- 영어: **Dice Orrery**
- 이유: 동명 게임이 없고, "주사위"와 "성계(별과 그 주위를 도는 천체 무리)"가 그대로 핵심 규칙을 말한다. 영어 Orrery(태엽으로 행성이 도는 모형 기계)는 화면의 놋쇠 기계 정체성과 이어진다. (R-032)
- 참고 링크: store.steampowered.com/app/5139570 (Orrery, 유틸리티), apps.apple.com "Solar Orrery", jettwilliams.itch.io/sumorbit
