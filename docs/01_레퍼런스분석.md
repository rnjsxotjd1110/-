# 01. 레퍼런스 분석

증분형(incremental) 게임: 숫자가 계속 커지고, 그 숫자로 더 빨리 커지는 장치를 사는 게임이에요. 방치형(idle)은 손을 떼도 진행되는 증분형을 말해요.

## 1. 호평받은 증분형

| 게임 | 호평 이유 | 이 게임이 가져올 "역할" |
| --- | --- | --- |
| Antimatter Dimensions | 층이 쌓일 때마다 새 규칙이 열린다(차원 → 무한 → 영원). 도전 과제가 "같은 게임을 다른 제약으로" 다시 보게 한다. 자동화가 지루한 클릭을 차례로 없애 준다 | 환생 층마다 새 시스템 해금, 제약 과제, 단계적 자동화 |
| Universal Paperclips | 같은 화면이 전혀 다른 게임으로 변해 간다. 이야기가 숫자와 함께 끝난다. 엔딩이 있다 | 화면이 성장과 함께 변함, 분명한 엔딩 |
| Cookie Clicker | 클릭 한 번의 손맛, 황금 쿠키 같은 짧은 이벤트, 업적의 양과 유머 | 누르면 바로 보이는 반응, 하늘 이벤트, 업적 |
| A Dark Room | 처음엔 버튼 하나, 조금씩 화면이 열린다. 설명 없이 스스로 알게 된다 | 튜토리얼 없는 점진적 해금 |
| Kittens Game | 자원이 서로 얽혀 선택이 생긴다. 균형 잡기의 재미 | 한 축이 막혀도 다른 축이 열려 있는 구조 |
| Melvor Idle | 오프라인 진행이 넉넉하고 정직하다. 돌아왔을 때 결과 보고가 분명하다 | 오프라인 보상 + 복귀 리포트 |
| NGU Idle / Realm Grinder | 환생 갈래(빌드)마다 플레이가 다르다 | 연구 갈래 선택 |

## 2. 혹평받은 증분형의 공통 불만

조사 출처: itch.io 증분형 댓글, Steam 리뷰 요약, 개발자 경험담(Subpixel "10 rules").

1. **후반에 기다리기만 한다.** "초반엔 쏟아지다가 후반엔 다음 업그레이드를 기다리는 게임이 된다."
2. **환생이 같은 길 반복이다.** "환생 후 다시 같은 버튼을 같은 순서로 사야 한다." 환생해도 새로 보는 것이 없다.
3. **방치형이라더니 손을 떼면 안 된다.** 보스, 이벤트, 관리 때문에 계속 붙어 있어야 한다.
4. **숫자만 커지고 화면은 그대로다.** 성장의 손맛이 없다.
5. **운이 지배한다.** 무작위 요소 때문에 운 나쁜 사람은 막히고 운 좋은 사람은 단계를 건너뛴다.
6. **정답 빌드가 하나다.** 한 업그레이드만 사면 되고 나머지는 쓸모없어진다.
7. **설명이 없거나 너무 많다.** 무엇이 무엇을 올리는지 알 수 없다 / 튜토리얼 벽.
8. **저장이 날아간다, 오프라인 진행이 없다.**
9. **소리가 거슬린다.** 짧은 클릭음이 수천 번 반복되면 피곤하다.
10. **결제·광고 유도.** 시간 단축 상품이 진행 벽을 만든다.

## 3. 반드시 지킬 것

- 처음 10초 안에 첫 행동(굴리기), 30초 안에 첫 구매가 있다
- 모든 구간에 "지금 할 수 있는 결정"이 1개 이상 있다. 다음 구매까지 2분 넘게 아무것도 못 하는 구간을 만들지 않는다
- 환생할 때마다 새로 보는 것(시스템, 천체 모습, 배경)이 있다
- 손을 떼도 진행된다. 손을 대면 더 빠르지만, 수동 효율은 자동의 3배를 넘지 않는다
- 성장이 화면으로 보인다: 천체가 자라고, 궤도가 늘고, 배경이 바뀐다
- 무작위는 짧게는 들쭉날쭉하되 길게는 고르게 수렴한다(운 보정 장치 포함). 시뮬레이터로 편차를 확인한다
- 업그레이드마다 쓸모가 끝까지 남거나, 쓸모가 끝나면 다음 업그레이드로 자연스럽게 대체된다
- 모든 수치는 마우스를 올리면 출처까지 볼 수 있다(통계 화면)
- 자동 저장, 오프라인 보상, 저장 내보내기/가져오기
- 소리는 기본 꺼짐, 짧고 부드럽게, 같은 소리 연속 재생 간격 제한

## 4. 절대 하지 않을 것

- 실제 시간 타이머로만 열리는 콘텐츠(그냥 기다리기)
- 결제, 광고, 시간 단축 상품
- 튜토리얼 팝업 연속, UI에 당연한 사실 설명
- 환생 후 전부 처음부터 같은 순서로 다시 사게 만드는 구조(환생 보상으로 시작 상태를 끌어올림)
- 클릭을 수천 번 강요하는 구조
- 놓치면 영구 손해인 이벤트
- 숫자만 늘어선 목록, 상자 안의 상자 세 겹 이상
