# 08. 밸런스 검증

도구: `node tools/sim.js <전략,...> <시드 수> <최대 시간(시)>` — 게임과 같은 `src/data.js`, `src/core.js`를 그대로 불러 0.5초 단위로 돌린다. 전체 결과 원본: `docs/sim_latest.txt`.

## 전략
| 전략 | 설명 |
| --- | --- |
| opt (최적) | 초당 3번 손 굴림(1시간), 이벤트 모두 잡음, 반응 1초, 눈 새기기를 기대 질량으로 평가 |
| normal (평범) | 초당 1번 손 굴림(10분), 이벤트 60%, 반응 8초 |
| idle (방치) | 첫 1분만 손 굴림, 이벤트 안 잡음, 반응 30초 |
| noforge | normal인데 눈을 한 번도 새기지 않음 |
| random (무작위) | 살 수 있는 것 중 무작위로 사고, 무작위로 눈을 깎음 |

## 운 편차
- 평범 전략 첫 초신성: 시드 10개에서 46.6~53.1분(±7%). 주사위 운으로 구간을 건너뛰거나 막히지 않는다. 굴림이 빨라지면 기대값 묶음 처리라 운 영향이 더 줄어든다.
- 엔딩 시점은 시드별 19.6~26.6시간. 후반 붕괴 이득의 편차가 원인.

## 찾아서 고친 것
| 문제 | 원인 | 수정 |
| --- | --- | --- |
| 16분 만에 엔딩 | 질량(쌓이는 값)에 생산이 정비례 → 폭주 | 생산 = 질량^0.6, 비용 증가율 상향 (D-013) |
| 눈을 안 새기면 6시간에도 초신성 못 함 (정답 하나) | 표준 분포 기준 희소도 + 같은 눈 정렬 고정 | 희소도를 현재 분포 기준으로, 정렬 배율 감쇠 (D-014, D-015). 이후 noforge 첫 초신성 64분 |
| 붕괴 직후 1분짜리 붕괴 150번 반복 | 붕괴 뒤에도 문턱 그대로 | 붕괴마다 우주가 무거워짐 (D-016) |
| 마지막 붕괴 사이 8시간 벽 | 무거워지는 속도가 너무 빠름 | 9번째부터 ×1.5로 완화 |
| 세 번째 주사위 1분 | 주사위 비용이 낮음 | 3개 12만, 4개 1,500만 (D-018) |

## 남은 한계
- 최적 플레이는 평범의 약 2배 빠르다(첫 초신성 21분). 손 굴림 효율이 자동의 2~3배라 목표("3배 이하") 안이다.
- 눈을 끝까지 새기지 않는 플레이는 붕괴(4.9시간)까지는 가지만 엔딩에 30시간 안에 닿지 못한다. 눈 새기기는 이 게임의 핵심 행동이라 의도된 범위로 둔다(D-021).
- 4~6시간 구간에서 평범 전략의 구매 간격이 최대 5~9분 벌어진다. 이때는 초신성을 반복해 별핵을 모으는 구간이라 할 일 자체는 있다.
