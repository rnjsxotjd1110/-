# 10. 콘텐츠 확장 (2026-11-24)

사용자 지시
- 주사위 면 바꾸기(눈 옮기기)를 완전히 삭제한다.
- 실행하면 컴퓨터가 버벅이고 크롬이 멈추는 문제를 고친다.
- 이름을 추상적으로 짓지 말고, 무엇을 강화하는지 이름에 바로 드러나게 한다.
- 스타크럼 때처럼 콘텐츠를 구체화한다. 조금 손보는 정도가 아니라 깊게 발전시킨다.
- 그래픽을 더 화려하게 다듬는다.

이 문서는 02_컨셉.md와 09_구조개편.md 위에 덮어쓴다. 겹치는 부분은 이 문서가 기준이다.

## 0. 한 줄 정의 (새로 정함)
> 문 닫기 직전의 산꼭대기 천문대에서, 야간 관측원이 주사위로 도는 놋쇠 오러리를 되살려 새 성계를 기록한다.

플레이어는 새로 온 야간 관측원이다. 관장·정비공·기록원 세 사람이 관측 일지와 무전으로 말을 건다. 화면에 사람 그림은 넣지 않는다. 이름표와 말투로만 구분한다. 이 부분은 02_컨셉의 "사람 캐릭터 없음"을 바꾼 것이다.

## 1. 삭제: 눈 옮기기 (확정)
- 주사위 눈은 언제나 표준값이다(d6: 1~6, d4: 1~4, d8: 1~8, d12: 1~12).
- 지우는 것
  - 판마다 옮기기 횟수
  - 주사위 탭의 면 두 번 클릭
  - 최대 눈 6·9
  - 연구 '숙련된 손'·'넘치는 눈'
  - 과제 '눈 옮기기 금지'
  - 업적 '첫 이동'·'아홉 개의 눈'
- 옛 저장의 옮긴 눈은 불러올 때 표준값으로 되돌린다.
- 분포를 고르는 결정은 주사위 개수, 주사위 모양(붕괴 뒤 d4·d8·d12), 특수 주사위 장착이 맡는다.

## 2. 이름 규칙 (확정)
- 이름은 "무엇을 + 장치"로 짓는다. 예: 별빛 렌즈 → 생산 렌즈, 무거운 눈 → 정렬 질량 추.
- 같은 종류는 번호를 붙인다: 생산 렌즈 1~6.
- 효과 수치는 이름 아래 설명줄에 쓴다.

| 이전 | 새 이름 |
| --- | --- |
| 별빛 렌즈 I~VI | 생산 렌즈 1~6 |
| 무거운 눈 / 납 눈 | 정렬 질량 추 1·2 |
| 매끈한 펠트 / 이중 톱니 / 시계 장인의 톱니 | 자동 굴림 톱니 1~3 |
| 조화의 현 I~III | 조화 현 1~3 |
| 공명 궤도 I·II | 이웃 궤도 공명기 1·2 |
| 혜성 그물 | 이벤트 보상 그물 |
| 깊은 망원경 / 심우주 망원경 | 드문 궤도 망원경 1·2 |
| 쌍둥이 쟁반 I·II | 한 번 더 굴림 쟁반 1·2 |
| 단단한 쟁반 | 굴림 질량 쟁반 |
| 중력 추 I·II | 단계 배율 추 1·2 |
| 잔해 회수 | 단계 상승 보너스 회수기 |
| 정렬 파문 | 정렬 확산 고리 |
| 바깥 고리 렌즈 / 안쪽 고리 렌즈 | 바깥 궤도 렌즈 / 안쪽 궤도 렌즈 |
| 질량 압축기 I·II | 단계 문턱 압축기 1·2 |
| 굴림 힘 / 태엽 굴림대 (기계 판) | 굴림 질량 / 자동 굴림 |

별핵 연구·특이점 연구·관측 과제도 같은 규칙으로 바꾼다. 실제 이름은 src/text.js에 있다.

## 3. 관측소 사람들 (새 시스템)
| 화자 | 하는 일 | 말끝 | 자주 쓰는 낱말 | 쓰지 않는 것 |
| --- | --- | --- | --- | --- |
| 한 관장 | 천문대 관장. 예산과 폐관을 걱정한다 | ~지요, ~겠네요 | 예산, 이사회, 기록, 옛날에는 | 반말, 느낌표 남발 |
| 정비공 도담 | 오러리 기계를 고친다 | ~요, ~거든요 | 톱니, 기름, 렌치, 야식 | 어려운 천문 용어 |
| 기록원 서하 | 대학원생. 도감과 일지를 쓴다 | ~네요, ~어요! | 도감, 사진, 논문, 커피 | 수치를 읽어 주는 말 |

- 진행 이정표마다 한 줄씩 나온다. 모두 40줄이다.
  - 이정표 예: 첫 굴림, 첫 미행성, 자동 굴림, 첫 의뢰, 첫 상자, 도감 5종, 적색 왜성, 초신성, 붕괴, 다면체, 엔딩 직전
- 나오는 자리는 성계 아래 띠다. 한 번에 하나만 6초 동안 보인다. 밀리면 최신 것만 남긴다(R-065).
- 지난 대사는 기록 탭의 "일지"에서 다시 본다.

## 4. 관측 의뢰 (새 시스템)
처음 자동 굴림을 사면 열린다. 한 번에 의뢰 하나가 기계 탭의 넷째 칸(눈 옮기기 자리)에 뜬다.

| 종류 | 목표 예 | 제한 시간 |
| --- | --- | --- |
| 궤도 | 궤도 9에 가스 거성 | 4분 |
| 정렬 | 정렬 3번 | 3분 |
| 하늘 | 하늘 이벤트 1번 잡기 | 4분 |
| 별가루 | 별가루 120만 모으기 (지금 생산 2분치) | 3분 |

- 궤도 목표는 지금 그 궤도 천체보다 한두 단계 위다. 가장 큰 천체보다 높게 잡지 않는다.
- 보상은 성공할 때마다 주사위 상자 1개다. 정렬·하늘 의뢰는 운명 굴림 1번을 더 준다.
- 실패하거나 끝나면 20초 뒤 새 의뢰가 온다. '다른 의뢰 받기'는 60초마다 한 번 쓸 수 있다.
- 의뢰를 내는 사람은 종류마다 정해져 있다.
  - 궤도: 서하
  - 정렬: 도담
  - 하늘: 서하
  - 별가루: 한 관장

## 5. 주사위 보관함 (새 시스템, 주사위 탭을 대체)
주사위 상자에서 특수 주사위가 나온다. 쟁반의 주사위 칸마다 특수 주사위를 하나씩 끼운다. 끼운 주사위의 모양(d4·d6·d8·d12)은 칸 모양을 따른다.

### 등급과 확률 (게임 안에 그대로 표시, R-021)
| 등급 | 확률 | 색 |
| --- | --- | --- |
| 보통 | 60% | 상아 |
| 드묾 | 28% | 청록 |
| 귀함 | 10% | 주황 |
| 전설 | 2% | 금 |

### 주사위 16종 (1성 기준 효과, 같은 주사위가 또 나오면 별이 오른다)
| 이름 | 등급 | 효과 |
| --- | --- | --- |
| 구리 주사위 | 보통 | 굴림 질량 +25% |
| 상아 태엽 주사위 | 보통 | 자동 굴림 간격 −6% |
| 흑요석 주사위 | 보통 | 정렬 질량 +40% |
| 산호 주사위 | 보통 | 홀수 합 궤도 질량 +50% |
| 청금석 주사위 | 보통 | 짝수 합 궤도 질량 +50% |
| 모래시계 주사위 | 보통 | 운명 굴림 충전 +20% |
| 유리 주사위 | 드묾 | 드문 궤도(희소도 4 이상) 질량 +70% |
| 은 주사위 | 드묾 | 이 주사위가 가장 큰 눈이면 그 굴림 질량 ×3 |
| 호박 주사위 | 드묾 | 하늘 이벤트 효과 +60% |
| 운석 주사위 | 드묾 | 단계 문턱 −8% |
| 진주 주사위 | 드묾 | 조화 +12% |
| 금 주사위 | 귀함 | 별가루 생산 +80% |
| 별유리 주사위 | 귀함 | 정렬하면 운명 굴림 충전 +15% |
| 혜성 주사위 | 귀함 | 한 번 더 굴림 확률 +12% |
| 성운 주사위 | 전설 | 모든 질량 ×2 |
| 블랙홀 주사위 | 전설 | 이 주사위 눈이 1이면 그 굴림 질량 ×8 |

- 별: 1~5성. 효과 = 1성 효과 × (1 + 0.5 × (별 − 1)). 5성은 1성의 3배다.
- 장착한 주사위만 효과가 있다. 같은 주사위는 한 칸에만 끼운다.
- 보관함은 초신성·붕괴 뒤에도 남는다.
- 상자를 여는 곳은 주사위 탭이다. 주사위가 굴러 나오며 등급 색 빛줄기가 터진다.
- '좋은 순서로 끼우기' 버튼은 지금 성계에서 효과가 큰 순서로 칸을 채운다.

### 상자를 얻는 곳
- 관측 의뢰 성공: 1개
- 초신성: 1개 (첫 초신성은 귀함 확정)
- 중력 붕괴: 3개
- 하늘 이벤트 잡기: 8% 확률로 1개

## 6. 천체 도감 (새 시스템)
천체 10단계마다 궤도 위치에 따라 세 갈래가 있다. 모두 30종이다.

| 갈래 | 조건 | 모습 |
| --- | --- | --- |
| 뜨거운 | 희소도 2 미만인 가운데 궤도 | 붉고 밝은 색으로 바뀜 |
| 온화한 | 그 사이 | 원래 색 |
| 차가운 | 희소도 4 이상인 바깥 궤도 | 푸르고 어두운 색으로 바뀜 |

- 처음 만나면 "새 천체 기록" 알림이 뜨고 도감에 그림이 채워진다.
- 한 종마다 별가루 생산 +3%. 30종을 다 모으면 +90%다.
- 별핵 연구 '도감 보너스 연구'를 사면 한 종마다 +6%가 된다(눈 옮기기 연구 자리를 대체).
- 성계 화면에서도 가운데 천체는 따뜻한 색, 바깥 천체는 차가운 색으로 보인다.
- 도감은 기록 탭의 둘째 화면이다. 그림 격자로 보여 주고, 수치는 고른 칸 설명에서만 보여 준다(R-043).

## 7. 바뀌는 연구·과제·업적
| 이전 | 새것 |
| --- | --- |
| 별핵 연구 '숙련된 손'(옮기기 +3) | 운명 충전 연구: 운명 굴림 충전 ×1.5 |
| 별핵 연구 '넘치는 눈'(눈 9개) | 도감 보너스 연구: 도감 한 종마다 +6% |
| 과제 '굳은 눈'(옮기기 금지) | 손 굴림 없는 관측: 손 굴림·운명 굴림 금지. 보상은 단계마다 운명 굴림 질량 +50% |
| 업적 '첫 이동' | 첫 상자: 주사위 상자를 열어요 |
| 업적 '아홉 개의 눈' | 다섯 별: 특수 주사위 하나를 5성으로 |
| (새 업적) | 도감 15종, 도감 30종, 전설 주사위, 의뢰 10번, 의뢰 50번 (모두 45개) |

## 8. 그래픽 (화려하게)
- 천체·별
  - 큰 천체(갈색 왜성 이상)와 중심별 둘레에 1~2px 빛 테를 두른다.
  - 별 단계는 십자 빛줄기가 천천히 돈다.
- 굴림 착지: 쟁반에 작은 불꽃 4~6개가 튀고, 맞은 궤도까지 빛줄기와 잔상이 남는다.
- 단계 상승: 충격파 고리와 함께 새 단계 이름이 크게 솟는다.
- 정렬·전설 주사위·운명 굴림: 화면 가장자리가 등급 색으로 번쩍이고, 별 조각이 터진다.
- 상자 열기: 상자가 흔들리다 열리고, 등급 색 빛줄기가 회전한다. 주사위가 굴러 나와 이름이 크게 뜬다.
- 특수 주사위는 재질 색(구리·흑요석·유리·금·성운 등)으로 그린다. 전설 주사위는 반짝임이 돈다.
- 조건: '움직임 줄이기' 설정을 켜면 번쩍임과 흔들림을 끈다. 모든 색은 팔레트 24색 안에서 쓰고, 바둑판 무늬(디더링)는 쓰지 않는다.

## 9. 성능 (확정, 반영함)
- 측정
  - 타이틀 화면에서 프레임마다 9.5ms를 썼다. 원인은 성운 배경을 프레임마다 픽셀 23만 개씩 다시 계산한 것이다.
  - 플레이 화면에서는 멈춘 주사위도 3D 계산으로 매번 다시 그리고 있었다.
- 수정
  - 성운은 위치가 1px 바뀔 때만 다시 만든다.
  - 멈춘 주사위와 9분할 판 그림은 한 번 그려 둔 것을 다시 쓴다.
  - 구르는 주사위는 픽셀마다 한 점만 본다.
  - 초당 60프레임을 넘지 않게 묶는다. 느린 컴퓨터는 자동으로 30프레임으로 낮춘다.
- 결과 (같은 기계 기준)
  - 타이틀: 9.5ms → 1.7ms
  - 플레이: 8.6ms → 3.4ms

## 10. 임의로 정한 사항 (보고 대상)
- 사람 세 명의 이름·성격·말투
- 의뢰 종류·시간·보상
- 특수 주사위 16종의 효과와 확률
- 도감 세 갈래의 조건과 보너스 크기
- 눈 옮기기 대체 연구 2개
- 손 굴림 없는 관측 과제
- 업적 45개로 늘림
