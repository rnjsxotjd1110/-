# 09. 구조 개편 설계 (스팀판 준비)

스팀판은 지금 웹 코드를 실행 창(Electron 등)으로 감싸 낸다. 포장 전에 고인물 검수(V3)에서 남은 구조 문제를 이 문서대로 고친다.

개편 대상: 눈 새기기, 관측 과제, 개량 30개, 후반 주사위 운.

## 1. 눈 새기기 → 눈 옮기기 (확정)
기존 문제(V3-4): ±1씩 새기고 비용이 1.9배씩 올라, 몇 번 새기면 더 나아지지 않는다. 최고 구성으로 가는 길에 손해 구간이 있고, 비용상 도달할 수도 없다. 새기지 않아도 엔딩 시간이 같다.

| 항목 | 결정 |
| --- | --- |
| 방식 | 주사위마다 눈 총합이 고정된다. 한 면의 눈 1개를 같은 주사위의 다른 면으로 옮긴다 |
| 결과 | 나오는 합의 평균은 그대로이고, 합이 퍼지는 정도만 바뀐다. 가운데 궤도를 두껍게 할지, 바깥 궤도를 노릴지 고른다 |
| 비용 | 판마다 옮기기 횟수. 판 시작 3회, 이번 판에서 처음 보는 천체 단계가 태어날 때마다 +2회. 별핵 연구로 시작 횟수를 늘린다. 되돌리기도 1회를 쓴다 |
| 최소 눈 | 0 (빈 면) 허용 |
| 최대 눈 | 한 면에 6개. 연구 '넘치는 눈'으로 9개 |
| 초신성 뒤 | 옮긴 눈은 유지, 횟수만 다시 채운다 |
| 조작 | 눈을 뺄 면 클릭 → 넣을 면 클릭 = 눈 1개 이동, 1회 사용 |
| 다면체 | 표준 눈 그대로. d4 총합 10, d8 36, d12 78. 최대 눈 제한은 같게 적용 |
| 바깥 궤도 보너스 상한 | 처음 ×4, 특이점 연구로 ×8, ×16 |

## 2. 관측 과제 (확정)
기존 문제(V3-5): 목표가 모두 "백색 왜성"이라 평소 구매 순서로 한 판 만에 끝난다. 보상 편차가 ×0.01~×5로 크다.

| 항목 | 결정 |
| --- | --- |
| 목표 | 궤도 지정 목표. 예: 단계 1 "궤도 7에 암석 행성", 단계 5 "궤도 2·12에 백색 왜성" |
| 단계 | 과제마다 5단계, 총 30번. 1~2단계는 초신성 구간, 3~5단계는 중력 붕괴 뒤에 열린다 |
| 보상 | 과제별 고유 효과가 단계마다 쌓인다. 크기는 시뮬레이터로 비슷하게 맞춘다 |

| 과제 | 규칙 | 보상(단계마다) |
| --- | --- | --- |
| 굳은 눈 | 눈 옮기기 금지 | 판 시작 옮기기 횟수 +1 |
| 두 개의 주사위 | 주사위 2개 고정 | 주사위 하나당 질량 증가 |
| 홀수 우주 | 짝수 궤도 생산 없음 | 홀수 궤도 생산 배율 |
| 불협화음 | 조화 없음 | 조화 증가 |
| 느린 태엽 | 태엽 간격 3초 고정 | 태엽 간격 감소 |
| 무거운 하늘 | 단계 문턱 ×10 | 단계 문턱 감소 |

## 3. 개량 30개 (확정)
기존 문제(V3-6): 보이면 싼 순서대로 다 사는 체크리스트다.

| 항목 | 결정 |
| --- | --- |
| 방식 | 기본 강화 18개는 그대로. 나머지 12개를 6쌍으로 묶어 둘 중 하나만 산다 |
| 바꾸기 | 초신성 때 개량이 모두 사라지므로 다음 판에서 다른 쪽을 고를 수 있다 |
| 쌍 후보 | 무거운 고리(정렬) ↔ 망원경(희소도), 공명(이웃 궤도) ↔ 쌍둥이 눈, 바깥 렌즈 ↔ 안쪽 렌즈, 정렬 확산 ↔ 혜성 파편 등 |
| 검증 | 쌍마다 눈 배치에 따라 유리한 쪽이 바뀌어야 한다. 시뮬레이터에서 양쪽이 모두 쓰이는지 확인한다 |

## 4. 후반 주사위 운 (확정)
기존 문제(V3-8, 9): 굴림이 빨라지면 기대값으로 묶여 운이 사라진다. 손 굴림과 이벤트는 매 판 앞부분에만 의미가 있다.

| 항목 | 결정 |
| --- | --- |
| 희귀 굴림 | 묶어서 계산하는 굴림에서도 정렬·끝 궤도 같은 희귀 결과는 실제로 추첨하고, 나오면 화면에 크게 보여 준다 |
| 운명 굴림 충전 | 태엽 굴림 수로 차오른다. 필요 굴림 수가 단계적으로 늘어 대략 2~4분에 한 번 |
| 운명 굴림 효과 | 손으로 굴려 나온 합의 궤도 천체에 큰 질량(예: 30초치 생산)을 바로 더한다. 희귀한 합일수록 크다. 관측 과제 궤도 목표에도 쓸 수 있다 |
| 쌓임 | 최대 3번까지 쌓인다 |

### 임의로 정한 세부 (보고 대상)
- 운명 굴림은 태엽 굴림대를 산 뒤에 열린다.
- 운명 굴림도 현재 눈 배치로 굴린다. 굴리기 전에 눈을 옮겨 원하는 궤도의 확률을 높이는 것도 허용한다.
- 눈은 같은 주사위 안에서만 옮긴다(주사위끼리 주고받지 않음). 주사위마다 성격이 유지되게 하려는 것이다.
- 기존 저장의 새긴 주사위는 총합을 표준값으로 맞추도록 바꾼다(눈이 넘치면 큰 면부터 줄인다).
